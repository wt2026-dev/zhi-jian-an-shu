# 视频生成加固修复报告

## 修复概览

针对 `src/server/services/videoGenerationService.ts` 集成的 Agnes AI 视频生成（按次计费）进行四项安全与资源治理加固，消除成本失控、资源堆积、SSRF 和事件循环阻塞风险。

## 3. URL 校验规则说明

`validateDownloadUrl(rawUrl)` 校验逻辑：

1. **协议限制**：仅允许 `http:` / `https:`，拒绝 `ftp:` / `file:` 等
2. **内网 IP 拒绝**：`localhost`、`127.x`、`10.x`、`172.16-31.x`、`192.168.x`、`169.254.x`、`0.x`、`::1`
3. **域名白名单**：配置 `AGNES_DOWNLOAD_HOST_WHITELIST` 后仅允许名单内域名

**绕过测试结果**：
- `ftp://evil.com/secret.mp4` → 拒绝（协议）
- `http://localhost:3000/secret.mp4` → 拒绝（内网）
- `http://10.0.0.1/secret.mp4` → 拒绝（内网）
- `http://172.16.0.1/secret.mp4` → 拒绝（内网）
- `http://192.168.1.1/secret.mp4` → 拒绝（内网）
- `http://169.254.1.1/secret.mp4` → 拒绝（内网）
- `not-a-url` → 拒绝（格式非法）
- `https://cdn.agnes-ai.cn/videos/abc.mp4` → ✅ 通过

## 5. 遗留风险与说明

1. **Agnes 侧限频对超时的影响**：Agnes 视频生成限频约 1 次/分钟，多段任务段间等待 65 秒。若 Agnes 侧响应变慢（如排队），单段轮询最多 10 分钟，加上段间等待，6 段任务总时长约 70+ 分钟。建议生产环境将 `AGNES_TOTAL_TIMEOUT_MIN` 设为 `90` 或更大。

2. **并发计数 finally 释放**：已在 `runFullVideoGeneration` 的 `finally` 块中执行 `runningTasks--`，确保无论成功/失败/超时都释放计数。这是此类修复最常见的翻车点——计数泄漏会导致功能永久锁死。

3. **审计日志**：当前任务 2 中的 `VIDEO_GEN_START` / `VIDEO_GEN_FAILED` 审计日志写入通过 `console.error` / `console.log` 输出。完整审计日志集成需要 `addAuditLog` 的 `req` 对象，而 `runFullVideoGeneration` 是后台异步执行无 `req` 可用。如需完整审计，建议在路由层（`handleGenerateVideoFull`）写 `VIDEO_GEN_START`，在 `runFullVideoGeneration` 中通过事件回调写 `VIDEO_GEN_FAILED`。

4. **配置热更新**：`isAgnesEnabled()` 等函数每次调用都读取 `process.env`，支持运行时通过 `process.env.AGNES_ENABLED = "true"` 动态开启，无需重启服务。
