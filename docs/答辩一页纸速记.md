# 答辩一页纸速记（答辩前 10 分钟过一遍）

> 全文背熟 3 段话术 + 6 个速答即可。所有说法有代码支撑，别超纲。

## 一、开场 30 秒（背这段）

> "我们做的是**以安全合规为底线、用 AI 加速**的设备检修全流程数字化闭环：报修 → 高危作业票/LOTO → 检修工单 → 质检归档，每一步受控、可追溯、经验可沉淀。
> 我们的创新不是 AI 本身，是 **AI 在工业场景的可靠性工程**——多模型可切换、失败自动降级且绝不伪造结果、生成内容人工审核 + 知识沉淀回流，全链路审计。"

## 二、创新点（评委问"你们创新在哪"就讲这三个）

| # | 创新点 | 一句话讲法 |
|---|---|---|
| 1 | AI 治理闭环 | AI 产出 → 人工审核闸 → 知识沉淀 → RAG 再引用，形成信任飞轮 |
| 2 | 攻击链回归测试 | 把真实漏洞（任意 JWT 拖源码）写成永久测试用例，安全基线默认拒绝 |
| 3 | AI+规则双轨可审计 | 同一功能双实现、可降级、可对比，每次调用/降级/切换都有审计 |

**包装口径**：工程创新 > 技术创新。**禁止**说"自研大模型 / 我们模型准确率 X%"。

## 三、AI 深度速答（Q："不就是调 API 吗"）

> "调 API 是能力数量，我们做的是容错（多模型路由+失败切换+审计）、密钥安全（AES-256-GCM 加密存储）、结果治理（审核闸+溯源）三层工程。能力分层我们内部很清楚：派单/报警是业务规则，诊断/方案是 RAG+生成，视觉是调 qwen-vl，支撑层全部自研。"

## 四、存储选型速答（Q："嵌入式数据库撑得起工业系统？"）

> "PGlite 是**演示形态**——嵌入式、零依赖、开箱即跑，跑的是标准 SQL；**生产走 DB_TYPE=postgres 一键切换**，适配器隔离 + 迁移工具 + 行数校验，每日 2:00 自动备份、保留 7 天、一键恢复。存储可替换，业务闭环才是系统。"
