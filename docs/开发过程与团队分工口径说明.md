## 三、原创性声明兼容性

1. **原创性体现**：业务建模（7 角色、29 表、工单状态机）、架构决策（AI 三层分层、PGlite 双模式、降级策略）、质量把关（237 用例的场景设计、安全基线定义）——这些是人工主导的核心工作。

2. **AI 辅助边界**：代码生成（路由/控制器/仓储层的模板代码）、批量文档整理（说明书格式统一）、测试用例生成（基于人工定义的验收标准）——AI 是提效工具，不构成代写。

3. **不声称"纯人工"**：项目 README 已明确说明使用了 AI 辅助工具；答辩口径中将主动说明 AI 在编码环节的辅助作用，同时强调人工决策的不可替代性。
