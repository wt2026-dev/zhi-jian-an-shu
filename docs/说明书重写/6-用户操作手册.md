# 用户操作手册

## 启动方式

```bash
docker compose up -d
```

浏览器打开 `localhost:3000`，系统自动初始化数据库并加载演示数据。

## 2 工单操作

### 2.1 创建工单（操作工/巡检员）

1. 点击左侧导航"工单管理" → 右上角"新建工单"
2. 填写表单：
   - **设备**：下拉选择设备（关联 `equipment` 表）
   - **故障类型**：选择预设类型（机械/电气/仪表/管道/其他）
   - **优先级**：低/中/高/紧急
   - **故障描述**：文本框输入详细描述
3. 点击"提交"按钮
4. 系统检查15分钟防重复：
   - 若重复 → 弹出 `409 DUPLICATE_ORDER` 提示，显示已有工单编号
   - 若不重复 → 创建成功，工单进入"已提交"状态

**工单编号格式**：`WO-20260914-001`（WO-日期-当日序号）

### 2.2 接单与派工（车间主任）

1. 进入"待派工"看板列
2. 点击工单卡片进入详情
3. 点击"指派"按钮，选择检修工
4. 工单状态变更为"已指派"

### 2.3 执行维修（检修工）

1. 在"我的工单"列表点击"接单"
2. 工单状态变为"进行中"
3. 记录维修过程：
   - 点击"添加评论"填写维修进度
   - 上传维修照片（支持jpg/png）
   - 填写实际工时
4. 维修完成后点击"提交审核"

### 2.4 审核与关闭（车间主任）

1. 进入"待审核"看板列
2. 查看维修记录和评论
3. 审核通过 → 工单状态变为"已完成"
4. 需返工 → 状态退回"进行中"
5. 已完成工单自动流转为"已关闭"

## 3 巡检操作

### 3.1 执行巡检（巡检员）

1. 点击左侧导航"巡检管理"
2. 查看今日巡检任务（日历视图）
3. 点击任务进入巡检表单
4. 逐项检查：
   - 扫描设备二维码签到
   - 勾选检查项（正常/异常/不适用）
   - 异常项填写备注并拍照
5. 全部完成后点击"提交巡检"

### 3.2 异常项处理

巡检发现异常时，系统自动弹出"创建报修工单"按钮，点击后自动关联设备信息，只需填写故障描述即可快速报修。

## 4 安全作业票

### 4.1 创建作业票

1. 在工单详情页点击"创建作业票"
2. 选择作业票类型：动火/受限空间/高处/临时用电/吊装/盲板抽堵
3. 填写作业内容、安全措施
4. 选择风险等级：低/中/高/极高
5. 点击"提交签署"

### 4.2 双人签署

1. 第一签名人（安全员）在"待签署"列表找到作业票
2. 确认安全措施到位后，点击"签署"按钮
3. 第二签名人（车间主任）执行相同操作
4. 双签完成后，作业票状态变为"已签署"

### 4.3 LOTO隔离

1. 作业票签署后，系统提示需要LOTO隔离
2. 进入"LOTO管理"页面
3. 选择锁具编号（如 LOTO-001）
4. 点击"上锁"，系统记录上锁时间和操作人
5. 维修完成后，点击"解锁"，需扫码+密码验证

## 5 AI助手

### 5.1 AI诊断

1. 在工单详情页点击"AI诊断"按钮
2. 系统通过 `/api/v1/ai/diagnose` 接口调用AI分析
3. 右侧结果区流式显示诊断内容：
   - 故障分类
   - 根因分析
   - 维修方案推荐
   - 置信度评分
4. 底部显示"推荐知识"卡片（来自 `/api/v1/ai/rag-search`）

### 5.2 知识库检索

1. 点击左侧导航"知识库"
2. 搜索框输入关键词（如"反应釜泄漏"）
3. 系统返回相关知识条目（含向量语义匹配）
4. 点击条目查看详细内容

### 5.3 AI降级说明

当AI服务不可用时：
- 系统自动降级，显示琥珀色提示条
- 返回本地规则引擎的简化诊断结果
- 降级日志记录在 `ai_analysis_log` 表

## 6 通知与审计

### 6.1 通知中心

- 右上角铃铛图标显示未读计数
- 通知类型：工单状态变更、作业票签署请求、AI诊断完成
- 点击通知跳转到对应详情页

### 6.2 审计日志

1. 管理员角色可访问"系统管理" → "审计日志"
2. 日志记录：操作人、操作类型、资源ID、IP地址、时间
3. 支持按时间范围、操作类型、用户筛选

## 7 常见问题

| 问题 | 解决方案 |
|------|---------|
| 提示"409 VERSION_CONFLICT" | 页面已过期，点击"刷新"获取最新数据 |
| 提示"409 DUPLICATE_ORDER" | 15分钟内已存在相同报修，点击"查看"跳转 |
| AI诊断无响应 | 检查网络连接，系统会自动降级到本地规则 |
| 页面加载慢 | 清除浏览器缓存，或检查PGlite数据文件大小 |
| 无法签署作业票 | 检查是否具有对应角色权限 |
