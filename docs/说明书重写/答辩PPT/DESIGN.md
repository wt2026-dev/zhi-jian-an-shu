# DESIGN — 工业设备智能检修一体化平台 · 答辩 PPT

## 画布 & 母版

- 画布尺寸：16:9 · 1280×720 px
- 三区母版：
  - **A 标题块**：0-100 px（顶部，主标题 + 副标题 + 页码）
  - **B 内容区**：100-660 px（核心展示）
  - **C 页脚条**：660-720 px（队伍信息 + 进度条）

## 配色（最多 4 种 hex）

| 色名 | 色值 | 用途 | 占比 |
|------|------|------|------|
| 主色（背景）| `#0b1220` (slate-950) | 全局底色 | ~60% |
| 辅色（卡片）| `#0f172a` (slate-900) | 卡片底色 | ~25% |
| 强调 1（青）| `#06b6d4` (cyan-500) | 主操作 / 链接 / 进行中 | ~8% |
| 强调 2（琥珀）| `#f59e0b` (amber-500) | 高优先级 / 警示 / 强调数据 | ~4% |
| 文字主 | `#e2e8f0` (slate-200) | 正文 | - |
| 文字辅 | `#64748b` (slate-500) | 弱化文字 / 说明 | - |
| 玫红警告 | `#f43f5e` (rose-500) | 仅作 critical 状态用 | <2% |

## 字体

- 中文：思源黑体（Source Han Sans / 苹方 / 微软雅黑）
- 英文：Inter / SF Pro
- 等宽：JetBrains Mono
- 大标题 ≥ 36 px，正文 16-20 px，数据数字 ≥ 48 px

## 页面类型映射

| 页 | 类型 | 视觉锚点 |
|----|------|----------|
| 01 | Hero 封面 | 项目名 ≥ 60 px + 关键数据 3 列 |
| 02 | 目录 | 5 大块卡片横排 |
| 03 | 痛点页 | 3 列卡片，每张 ≥ 200 px |
| 04 | 架构页 | 3 层架构图（带连接线）|
| 05 | 流程页 | 7 节点状态机时间轴 |
| 06 | 表格页 | 7 角色 × 5 权限列 |
| 07 | 演示页 | 5 张缩略图横排（截图占位） |
| 08 | 演示页 | 大图占 60% B 区 |
| 09 | AI 页 | 4 层 × 5/10/5/4 网格 |
| 10 | DB 页 | 简化 ER 图 + 数字大字号 |
| 11 | 创新页 | 3 列并列，每列 ≥ 200 px |
| 12 | 结尾 | 关键数字 4 列 + 致谢 |

## 留白规则

- 每页留白 ≤ 35%
- 卡片内边距 ≥ 24 px
- 元素间距 ≥ 16 px

## 禁止

- 不要 emoji
- 不要 3D 效果
- 不要复杂渐变（仅主背景到辅色的线性渐变）
- 不要中文字体回退成楷体（思源黑体优先）
