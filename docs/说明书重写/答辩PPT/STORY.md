# STORY — 工业设备智能检修一体化平台 · 答辩 PPT

## 作品定位

本作品面向**流程制造企业**，解决设备维修管理中信息孤岛、流程断裂、知识流失三大痛点。通过数字化手段实现从巡检发现 → 报修 → 调度 → 维修 → 验收 → 知识沉淀的全链路闭环。

## 受众 & 目标

- **受众**：评审专家（双一流高校工科背景，熟悉工业自动化 / 软件工程）
- **场景**：复赛答辩 + 决赛答辩（10 分钟讲解 + 5 分钟问答）
- **目标**：30 秒抓眼球（痛点）、3 分钟讲清楚"为什么"（动机）、3 分钟讲清楚"是什么"（架构）、3 分钟讲清楚"怎么样"（演示 + 数据）、1 分钟讲清楚"差异化在哪"（创新点）

## 叙事节奏

- **01-02**：1 分钟——抓眼球 + 给出全局导航
- **03-06**：2 分钟——痛点 → 方案 → 流程 → 角色（从「为什么」到「是什么」）
- **07-09**：2 分钟——演示 + AI + DB（用真东西说话）
- **10-12**：1 分钟——创新点 + 总结（差异化 + 收束）

## 关键术语清单（评审口径）

- **PGlite**：WASM 内嵌的 PostgreSQL，开发 / 测试零部署
- **OpenAI 兼容端点**：本项目用 OpenAI SDK 7.10 指向 DashScope 兼容模式（不是 dashscope-sdk）
- **pgvector**：生产 PostgreSQL 的向量扩展（开发 PGlite 无 → JSONB 降级）
- **Pointer Capture**：跨 iframe 拖拽的关键 API（HTML5 标准）
- **SSE**：Server-Sent Events，AI 流式输出的协议

## 视觉设计原则

- 工业暗色主题（slate-950 深蓝灰底 + 青 #06b6d4 / 琥珀 #f59e0b 强调色）
- 信息密度高（每页至少一个视觉锚点 ≥ 44px 或 ≥ 40% B 区面积图）
- 数字 / 流程优先于文字
- 关键数据用大字号 ≥ 48px 突出
