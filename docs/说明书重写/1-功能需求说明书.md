# 功能需求说明书

## 场景驱动的需求定义

冶金车间反应釜温度异常：操作工发现温度传感器读数超过阈值，扫码报修，系统自动生成高危作业票，触发双人会签+LOTO隔离流程，检修工单流转闭环，AI诊断辅助生成维修建议，故障经验沉淀至知识库。整个链条涉及巡检、报修、调度、维修、安全、质检、知识管理七个角色协同。

---

## 1 角色与权限矩阵

系统采用 RBAC 模型，权限码格式为 `module:action`，共定义 7 个角色：

| 角色 | 权限码集合 | 典型操作 |
|------|-----------|---------|
| admin（系统管理员） | `*:*` | 全部权限，含用户管理、系统配置 |
| manager（车间主任） | `order:read,write,close` `ticket:approve` `report:read` | 工单审批、作业票审批、报表查看 |
| tech1（检修工-主修） | `order:read,work,comment` `ticket:sign` `ai:diagnose` | 工单接单、执行维修、签名确认 |
| tech2（检修工-副修） | `order:read,work,comment` `ticket:sign` | 工单执行、副签 |
| inspector（巡检员） | `inspection:read,write` `order:create` | 巡检记录、创建报修工单 |
| operator（操作工） | `order:create,read` `ticket:create` | 报修、查看进度、创建作业票 |
| archivist（知识管理员） | `knowledge:read,write,delete` `rag:query` | 知识库维护、RAG检索 |

**权限校验位置**：每个 API 路由入口处通过中间件校验 `req.user.role` 是否包含目标权限码，未匹配返回 `403 FORBIDDEN`。

## 2 功能需求清单（FR-01 ~ FR-07）

### FR-01 工单全生命周期管理

**工单编号规则**：`WO-{YYYYMMDD}-{SEQ}`，序号每日重置，防重复窗口为 15 分钟。

**状态机定义**：

```
ALLOWED_TRANSITIONS = {
  draft:      ['submitted'],
  submitted:  ['assigned', 'cancelled'],
  assigned:   ['in_progress', 'cancelled'],
  in_progress:['pending_review', 'on_hold'],
  pending_review: ['completed', 'in_progress'],
  on_hold:    ['in_progress'],
  completed:  ['closed'],
  closed:     [],
  cancelled:  []
}
```

**防重复提交**：同一操作工在 15 分钟内对同一设备提交相同故障类型，系统返回 `409 VERSION_CONFLICT`，前端弹出已有工单链接。

**乐观锁机制**：每次更新携带 `version` 字段，SQL 条件为 `WHERE id=? AND version=?`，匹配失败返回 `409 VERSION_CONFLICT`。

### FR-02 巡检计划与执行

巡检计划支持按班次（早/中/晚）、设备类型、巡检路线配置。巡检员手持终端扫码签到，系统记录 GPS 坐标与时间戳。异常项自动关联报修工单。

### FR-03 六类作业票

| 作业票类型 | 必签角色 | 关联LOTO |
|-----------|---------|---------|
| 动火作业 | 安全员+车间主任 | 是 |
| 受限空间 | 安全员+技术主管 | 是 |
| 高处作业 | 安全员+车间主任 | 是 |
| 临时用电 | 安全员+电气主管 | 否 |
| 吊装作业 | 安全员+车间主任 | 是 |
| 盲板抽堵 | 安全员+技术主管 | 是 |

每类作业票包含：作业单位、作业内容、风险等级（低/中/高/极高）、安全措施列表、双人签名时间戳。LOTO 锁具编号录入 `loto_locks` 表。

### FR-04 AI诊断辅助

**20 项 AI 能力分三层架构**：

| 层级 | 能力 | 接口 |
|------|------|------|
| 基础层（5项） | 故障分类、严重度评估、关键词提取、工单摘要、设备状态解读 | `/api/v1/ai/chat` |
| 分析层（10项） | 根因分析、维修方案推荐、备件预测、关联故障发现、趋势预警、知识匹配、风险评估、效率分析、成本估算、方案对比 | `/api/v1/ai/diagnose` |
| 决策层（5项） | 维修决策树、应急预案生成、资源调度建议、停机损失评估、改进建议 | `/api/v1/ai/suggest-followups` |

### FR-05 知识库与RAG检索

故障案例、维修手册、安全规程存入 `knowledge_embeddings` 表，使用 pgvector 向量索引。检索接口 `/api/v1/ai/rag-search`，支持语义搜索与关键词混合检索。每次检索返回 Top-5 相关文档，附带相似度评分。

### FR-06 设备遥测与预警

6 个遥测维度：温度、压力、振动、电流、流量、转速。数据存入 `equipment_telemetry` 表，字段含 `metric_name`、`metric_value`、`unit`、`recorded_at`。超阈值自动触发预警工单。

### FR-07 通知与审计日志

全系统操作日志存入 `audit_logs` 表，字段含 `user_id`、`action`、`resource_type`、`resource_id`、`ip_address`、`created_at`。关键操作（工单创建、作业票签发、LOTO上锁/解锁）强制记录。通知支持站内消息与 WebSocket 推送。

## 3 非功能需求

| 维度 | 指标 |
|------|------|
| 并发 | 支持 200 用户同时在线 |
| 响应 | 页面加载 < 2s，API 响应 < 500ms |
| 可用性 | 单机部署，本地网络依赖 |
| 安全 | JWT 令牌鉴权，密码 bcrypt 哈希 |
| 数据 | PGlite 嵌入式存储，支持导出 JSON |
