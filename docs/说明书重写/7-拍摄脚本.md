# 拍摄脚本

## 作品定位

本作品面向流程制造企业，解决设备维修管理中信息孤岛、流程断裂、知识流失三大痛点。通过数字化手段实现从巡检发现→报修→调度→维修→验收→知识沉淀的全链路闭环。

---

## 1 拍摄准备

### 1.1 环境准备

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 或 macOS |
| Docker | Docker Desktop 最新版 |
| 浏览器 | Chrome 120+（无插件干扰） |
| 分辨率 | 1920×1080（录屏） |
| 网络 | 稳定连接（AI服务依赖网络） |

### 1.2 启动命令

```bash
docker compose up -d
```

浏览器打开 `localhost:3000`

### 1.3 测试数据

系统预置以下演示数据：
- 29张业务表（23个幂等迁移文件初始化）
- 9个演示账号
- 示例设备、工单、巡检计划

---

## 2 十个分镜

### 分镜1：开场（30秒）

**画面**：工业厂区远景 → 反应釜特写 → 温度仪表盘异常跳动

**解说**：
> 冶金车间反应釜温度异常，操作工发现传感器读数超过阈值。传统模式下，纸质工单流转慢、信息传递易失真、维修经验随人员流动而丢失。我们用数字化手段，让每一个环节都可追踪、可审计、可沉淀。

**时间**：00:00 - 00:30

---

### 分镜2：系统启动（20秒）

**画面**：终端窗口输入启动命令 → 浏览器打开 → 登录页

**解说**：
> 系统基于Docker容器化部署，一条命令启动。打开浏览器，输入localhost:3000，进入工业风暗色主题登录界面。

**时间**：00:30 - 00:50

**操作**：
```bash
docker compose up -d
```
打开 `localhost:3000`

---

### 分镜3：报修流程（40秒）

**画面**：操作工登录 → 新建工单 → 填写表单 → 提交 → 看板显示新工单

**解说**：
> 操作工登录系统，点击新建工单。选择故障设备，填写故障描述。系统自动检查15分钟防重复，确保同一设备不会被重复报修。工单编号WO-20260914-001自动生成，状态流转至待派工。

**时间**：00:50 - 01:30

**关键操作**：
- 使用 operator 账号登录
- 点击"新建工单"
- 填写设备、故障类型、优先级、描述
- 点击"提交"
- 工单出现在看板"待处理"列

---

### 分镜4：作业票签署（40秒）

**画面**：创建作业票 → 选择类型 → 填写内容 → 第一人签署 → 第二人签署 → 状态变为已签署

**解说**：
> 高危作业需要双人会签。创建动火作业票，安全员确认安全措施后签署，车间主任复核后签署。两道确认，确保安全措施到位。LOTO锁具同步登记，设备进入隔离状态。

**时间**：01:30 - 02:10

**关键操作**：
- 在工单详情页点击"创建作业票"
- 选择"动火作业"
- 填写安全措施
- 使用 manager 账号签署
- 第二人签署完成

---

### 分镜5：工单执行（40秒）

**画面**：检修工接单 → 维修记录 → 上传照片 → 提交审核

**解说**：
> 检修工收到指派通知，点击接单开始维修。在工单中记录维修过程、更换备件、实际工时。上传维修现场照片作为凭证。维修完成后提交审核。

**时间**：02:10 - 02:50

**关键操作**：
- 使用 tech1 账号登录
- 在"我的工单"点击"接单"
- 添加评论记录维修过程
- 上传维修照片
- 点击"提交审核"

---

### 分镜6：AI诊断（50秒）

**画面**：点击AI诊断按钮 → 流式输出结果 → 置信度评分 → 知识库推荐

**解说**：
> 系统集成20项AI能力，分三层架构：基础层进行故障分类和严重度评估，分析层提供根因分析和维修方案推荐，决策层生成应急预案和资源调度建议。诊断结果通过SSE流式传输，逐字呈现分析过程。系统自动匹配知识库中的相关案例，为维修决策提供参考。

**时间**：02:50 - 03:40

**关键操作**：
- 在工单详情页点击"AI诊断"
- 观察右侧结果区流式输出
- 查看置信度评分
- 浏览底部知识库推荐

---

### 分镜7：知识沉淀（30秒）

**画面**：知识库页面 → 搜索故障案例 → 查看向量匹配结果 → 新建知识条目

**解说**：
> 每次故障处理的经验都沉淀到知识库。通过向量嵌入技术，系统能理解语义相似性，即使描述不同也能找到相关案例。下次遇到类似故障，AI诊断时会自动调用历史经验。

**时间**：03:40 - 04:10

**关键操作**：
- 使用 archivist 账号登录
- 点击"知识库"
- 搜索"反应釜温度异常"
- 查看匹配结果
- 新建一条知识条目

---

### 分镜8：审计追踪（20秒）

**画面**：审计日志页面 → 筛选操作类型 → 查看详细记录

**解说**：
> 全系统操作留痕，从工单创建到作业票签署，从LOTO上锁到AI诊断，每一步操作都记录在审计日志中。操作人、操作时间、操作内容、IP地址，确保责任可追溯。

**时间**：04:10 - 04:30

**关键操作**：
- 使用 admin 账号登录
- 点击"系统管理" → "审计日志"
- 筛选"工单创建"操作
- 查看日志详情

---

### 分镜9：报表概览（30秒）

**画面**：报表中心 → 工单统计图表 → 设备健康度 → 数据导出

**解说**：
> 管理者可通过报表中心掌握全局。工单统计展示处理效率，设备健康度热力图预警潜在风险，安全合规率环形图反映管理水平。支持一键导出数据，便于汇报决策。

**时间**：04:30 - 05:00

**关键操作**：
- 使用 manager 账号登录
- 点击"报表中心"
- 查看工单统计图表
- 查看设备健康度热力图
- 点击"导出数据"

---

### 分镜10：结尾（20秒）

**画面**：系统全景 → 核心数据总结 → 团队致谢

**解说**：
> 系统包含29张业务表、23个幂等迁移、20项AI能力、33个测试文件共234个测试用例。从需求到代码，从测试到文档，我们构建了一套完整的工业维护数字化解决方案。

**时间**：05:00 - 05:20

## 3 录制注意事项

### 3.1 操作规范

- 每个操作步骤之间停顿2-3秒，便于后期剪辑
- 鼠标移动平稳，避免快速晃动
- 点击操作前稍作悬停，让观众看清按钮位置
- 表单填写使用真实感数据（设备名称、故障描述）

### 3.2 画面规范

- 浏览器全屏显示，隐藏书签栏和扩展图标
- 字体大小适中，确保1080p下清晰可读
- 暗色主题下避免高亮内容刺眼
- 关键操作区域可用录屏工具画圈标注

### 3.3 解说规范

- 语速适中，每分钟180-200字
- 关键术语准确（LOTO、SSE、RAG等）
- 操作步骤与解说同步
- 结尾总结数据准确：29张表、23迁移、20项AI、33测试文件234用例

### 3.4 常见问题

| 问题 | 预防措施 |
|------|---------|
| AI诊断无响应 | 提前测试网络，准备离线演示方案 |
| 页面加载慢 | 清除缓存，关闭无关程序 |
| 登录失败 | 确认演示账号密码正确 |
| 截图模糊 | 使用系统原生截图，避免压缩 |
