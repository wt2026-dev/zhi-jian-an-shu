# 数据库设计说明书

## 数据架构起点

23个幂等迁移文件（001-023）定义29张业务表，PGlite与PostgreSQL双模式兼容。向量检索依赖pgvector扩展，JSONB字段承载灵活业务数据。

---

## 1 迁移架构

迁移文件命名规则：`{序号}-{描述}.sql`，执行顺序严格递增。每次迁移包裹在事务中，失败自动回滚。

```sql
-- schema_migrations 记录已执行迁移
CREATE TABLE schema_migrations (
  version VARCHAR(10) PRIMARY KEY,
  executed_at TIMESTAMP DEFAULT NOW()
);
```

## 3 核心表结构详解

### 3.1 work_orders（工单主表）

```sql
CREATE TABLE work_orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_no VARCHAR(32) UNIQUE NOT NULL,
  title VARCHAR(200) NOT NULL,
  description TEXT,
  equipment_id UUID REFERENCES equipments(id),
  fault_type VARCHAR(50),
  priority VARCHAR(10) NOT NULL DEFAULT 'medium',
  status VARCHAR(20) NOT NULL DEFAULT 'draft',
  creator UUID REFERENCES users(id),
  assignee UUID REFERENCES users(id),
  version INTEGER NOT NULL DEFAULT 1,
  safety_requirements JSONB DEFAULT '{}',
  repair_log JSONB DEFAULT '{}',
  acceptance JSONB DEFAULT '{}',
  created_timestamp BIGINT,
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_work_orders_status ON work_orders(status);
CREATE INDEX idx_work_orders_equipment ON work_orders(equipment_id);
CREATE INDEX idx_work_orders_creator ON work_orders(creator);
CREATE INDEX idx_work_orders_created_at ON work_orders(created_at DESC);
```

### 3.2 equipment_telemetry（设备遥测）

```sql
CREATE TABLE equipment_telemetry (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  equipment_id UUID REFERENCES equipment(id),
  metric_name VARCHAR(50) NOT NULL,  -- temperature/pressure/vibration/current/flow/speed
  metric_value DECIMAL(12,4) NOT NULL,
  unit VARCHAR(20) NOT NULL,         -- ℃/MPa/mm/s/A/L·min⁻¹/rpm
  quality VARCHAR(10) DEFAULT 'good', -- good/bad/uncertain
  source VARCHAR(50) DEFAULT 'manual', -- manual/sensor/scada
  recorded_at TIMESTAMP NOT NULL DEFAULT NOW()
);

CREATE INDEX idx_telemetry_equipment ON equipment_telemetry(equipment_id);
CREATE INDEX idx_telemetry_name_time ON equipment_telemetry(metric_name, recorded_at DESC);
```

**6个遥测维度**：温度（℃）、压力（MPa）、振动（mm/s）、电流（A）、流量（L·min⁻¹）、转速（rpm）

### 3.3 knowledge_embeddings（知识向量）

```sql
CREATE TABLE knowledge_embeddings (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  article_id UUID REFERENCES knowledge_articles(id),
  embedding vector(1536),
  model VARCHAR(50) NOT NULL DEFAULT 'text-embedding-v2',
  chunk_text TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE INDEX idx_embeddings_article ON knowledge_embeddings(article_id);
-- 向量相似度索引
CREATE INDEX idx_embeddings_vector ON knowledge_embeddings 
  USING ivfflat (embedding vector_cosine_ops) WITH (lists = 100);
```

### 3.4 loto_locks（LOTO锁具）

```sql
CREATE TABLE loto_locks (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  lock_no VARCHAR(20) UNIQUE NOT NULL,   -- LOTO-001
  equipment_id UUID REFERENCES equipments(id),
  status VARCHAR(20) DEFAULT 'available', -- available/locked/lost
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 4 索引与完整性

### 4.1 全局索引策略

- 所有外键字段自动建索引
- 时间字段降序索引（用于列表查询）
- 状态字段索引（用于筛选）
- JSONB 字段 GIN 索引（extra 字段）

### 4.2 数据完整性约束

```sql
-- 用户名唯一
ALTER TABLE users ADD CONSTRAINT uq_users_username UNIQUE (username);

-- 工单编号唯一
ALTER TABLE work_orders ADD CONSTRAINT uq_work_orders_order_no UNIQUE (order_no);

-- 作业票状态枚举
ALTER TABLE work_order_tickets ADD CONSTRAINT ck_ticket_status 
  CHECK (status IN ('pending', 'signed', 'rejected', 'expired'));

-- 遥测值非负
ALTER TABLE equipment_telemetry ADD CONSTRAINT ck_telemetry_value 
  CHECK (metric_value >= 0);

-- LOTO锁状态枚举
ALTER TABLE loto_locks ADD CONSTRAINT ck_lock_status 
  CHECK (status IN ('available', 'locked', 'lost'));
```
