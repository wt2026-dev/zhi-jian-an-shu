# 界面设计书

## 设计起点

工业暗色主题：slate-950 深蓝灰底 + 青（#06b6d4）/琥珀（#f59e0b）/玫红（#f43f5e）高对比强调色。兼顾工业现场强光可读与长时间操作护眼。

---

## 1 设计原则

### 1.1 六大脑区布局

```
┌─────────────────────────────────────────────────┐
│  ① 全局导航栏（Logo / 搜索 / 通知 / 用户头像）  │
├────────┬────────────────────────────────────────┤
│        │                                        │
│ ② 侧边 │  ③ 主工作区                           │
│   导航  │                                        │
│        │                                        │
│ ④ 快捷 │                                        │
│   操作 │                                        │
│        │                                        │
├────────┴────────────────────────────────────────┤
│  ⑤ 状态栏（连接状态 / AI状态 / 环境信息）       │
│  ⑥ 面包屑 + 当前位置                           │
└─────────────────────────────────────────────────┘
```

| 脑区 | 功能 | 视觉处理 |
|------|------|---------|
| ① 全局导航栏 | 系统标识、全局搜索、消息通知、用户菜单 | slate-900 背景，固定顶部 |
| ② 侧边导航 | 模块级导航，10个功能模块 | slate-950 背景，hover 时 slate-800 |
| ③ 主工作区 | 业务内容展示，表格/表单/看板 | slate-950 背景，卡片 slate-900 |
| ④ 快捷操作 | 常用操作按钮组 | 固定底部，重要操作突出色 |
| ⑤ 状态栏 | 系统连接状态、AI服务状态、当前环境 | 固定底部，小字体 |
| ⑥ 面包屑 | 页面层级导航，当前位置 | slate-500 文字，可点击跳转 |

## 2 状态色语义系统

| 状态 | 色值 | 含义 | 应用场景 |
|------|------|------|---------|
| 玫红 #f43f5e | 紧急/critical | 最高优先级，需立即处理 | 工单紧急状态、危险警告 |
| 琥珀 #f59e0b | 高/high | 较高优先级，优先安排 | 工单高优先级、待审批 |
| 青 #06b6d4 | 进行中/in_progress | 当前执行中 | 工单进行中、巡检中 |
| 翠绿 #10b981 | 成功/completed | 已完成 | 工单完成、巡检通过 |
| 紫 #8b5cf6 | 隔离/locked | LOTO隔离中 | 锁具上锁、设备隔离 |
| slate-500 | 低/默认 | 普通状态 | 草稿、已关闭 |

## 3 十大页面布局

### 3.1 登录页

居中卡片布局，工业风暗色背景。用户名/密码输入框 + 角色快捷选择（9个演示账号一键填入）。登录按钮使用青色（#06b6d4）高亮。

### 3.2 工单看板（首页）

三列看板布局：待处理（左）→ 进行中（中）→ 已完成（右）。每张卡片显示：工单编号、设备名称、优先级色条、创建时间、负责人头像。支持拖拽移动状态。

### 3.3 工单详情页

左侧：工单基本信息（状态流转时间轴）。右侧：关联作业票、巡检记录、AI诊断结果。底部：评论与操作记录。409冲突时弹出橙色警告条，显示"数据已被修改，请刷新"。

### 3.4 巡检任务页

日历视图 + 列表视图切换。已巡检项显示绿色对勾，异常项显示玫红警告。支持扫码签到（调用摄像头）。

### 3.5 作业票签署页

全屏表单，顶部显示作业票类型标签。必填字段标红星，未填写时提交按钮禁用（灰色）。双人签名区：第一签名区完成后自动展开第二签名区。签名完成按钮变为翠绿色。

### 3.6 LOTO管理页

设备拓扑图 + 锁具列表。已上锁设备显示紫色图标，解锁需扫码+密码双重验证。锁具颜色编码：红=动力锁、蓝=仪表锁、黄=安全锁。

### 3.7 AI诊断页

左半屏：工单详情。右半屏：AI诊断结果流式输出，逐字渲染。底部：知识库推荐（Top-5相关文档卡片）。AI不可用时显示降级提示条（琥珀色背景）。

### 3.8 知识库页

树形分类导航 + 列表内容。支持全文搜索和语义搜索切换。编辑器使用 Markdown 格式，支持图片和代码块。

### 3.9 报表中心

数据概览仪表盘：工单统计（柱状图）、设备健康度（热力图）、安全合规率（环形图）。支持时间范围筛选和数据导出。

### 3.10 系统管理页

用户管理表格 + 角色权限配置。用户列表支持搜索、筛选、批量操作。角色权限矩阵可视化展示。

## 4 关键交互设计

### 4.1 AI流式体验

```
用户点击"AI诊断"
  → 按钮变为加载态（旋转图标 + "诊断中..."）
  → 右侧结果区出现光标闪烁效果
  → 逐字渲染诊断结果（每50ms一个字符）
  → 渲染完成后显示置信度评分
  → 底部展开"推荐操作"卡片
```

### 4.2 表单防错409

```
用户提交表单
  → 前端校验（必填/格式）
  → API返回409 VERSION_CONFLICT
  → 弹出橙色警告对话框
  → 显示冲突详情（谁在何时修改了什么）
  → 提供"查看最新数据"按钮
  → 用户确认后刷新表单（保留已填内容）
```

### 4.3 作业票签署流程

```
第一签名人完成签名
  → 签名区缩小为已签状态（头像+时间）
  → 第二签名区从右侧滑入
  → 第二签名人签名
  → 状态变为"已签署"（翠绿色）
  → 自动触发关联工单状态流转
```

### 4.4 通知推送

```
事件发生（工单创建/作业票签署/AI诊断完成）
  → 服务端推送WebSocket消息
  → 浏览器右上角弹出通知卡片
  → 3秒后自动收起到通知中心
  → 通知中心红点+未读计数
```
