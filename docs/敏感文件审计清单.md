# 敏感文件历史全量审计清单

> 审计日期：2026-09-13　|　仓库：工业设备智能检修与作业协同系统（本地 master）
> 审计范围：git 全部历史对象（`git rev-list --objects --all`）

## 一、审计方法

1. **路径级**：`git rev-list --objects --all` 列出全部历史对象路径（去重后 **577** 个），逐一比对敏感模式：
   `.env`、`.env.*`（保留 `.env.example`）、`node_modules/`、`data/`、`archive/`、`scratch_shots/`、`scratch/`、`logs/`、`backups/`、`*.log`
2. **内容级**：扫描全部 **715 个 blob 对象**的实际内容，匹配真实凭据模式：
   `DASHSCOPE_API_KEY=sk-…`、任意 `sk-` 前缀密钥（≥28 位）、`JWT_SECRET=<64 位十六进制>`、真实微信 AppID（`wx` + 16 位十六进制）

## 二、审计结果

| 路径级：`.env` / `.env.*`（除 `.env.example`） | **0 个**历史残留 |

## 三、结论

**0 个历史残留。** 敏感文件（`.env`、运行时数据、日志、依赖、调试产物）从未进入任何提交，
无需执行 `git filter-repo` / `filter-branch` 历史清洗，无需轮换任何已泄露凭据。
