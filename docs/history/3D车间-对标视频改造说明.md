# 3D 生产车间「对标视频」改造说明

> 日期：2026-09-18
> 目标：按参考视频 BV18T421v7no 的形态，把现有 3D 场景升级为
> **厂区总览 → 车间生产线 → 单设备聚焦** 三级结构。
> 原则：沿用现有 Three.js 引擎（不引入新库、不推倒重来），在既有引擎上扩展。

---

## 一、三级结构怎么用

| 层级 | 进入方式 | 画面内容 |
|---|---|---|
| **厂区总览** | 点 HUD 顶栏面包屑「厂区总览」，或调 `enterFactoryLevel()` | 3–5 栋厂房建筑群 + 道路 + 空地，每栋顶部带名称标签 |
| **车间** | 在总览层**点击某栋厂房**下钻；或从设备聚焦返回 | 沿墙布置的真实台账设备 + 中轴机械臂产线 + 传送带 + 物料箱 + 分区牌 |
| **单设备** | 点击车间内任意设备（或机械臂工作站） | 只显示该设备；有故障部位时相机对准该部位并显示红标 |

相机在两级之间走**既有轨道阻尼插值**（指数阻尼），是"推近/拉远"而不是跳变。

- 下钻：`scene.drillIntoBuilding(buildingId)`
- 返回：`scene.enterWorkshopLevel()`

## 二、P0 车间生产线（原先完全缺失）

`src/components/equipment3d/productionLine.ts`

| 元素 | 实现 |
|---|---|
| 机械臂工作站 | 4–6 台（数量夹在 4–6），双侧交错布置在中轴两侧，各配基座工作台 |
| 编号牌 | 实体立牌（近景）+ 恒定屏幕尺寸 Sprite（远景可读）：`机械臂 001 … 006` |
| 传送带 | 机架纵梁 + 支腿 + 带面（贴图滚动）+ 滚轮（InstancedMesh）+ 驱动电机与风扇 |
| 蓝色物料箱 | 半透明蓝箱体 + 内容物，InstancedMesh，间隔摆放并缓速移动 |
| 异常警示浮标 | 红三角感叹号 Sprite，上下浮动 + 脉冲缩放；**故障/告警设备才有，正常设备没有** |
| 分区立牌 | 半透明立板 + 发光文字（CanvasTexture），车间两端各一 |
| 车间环境 | 保留既有柱网/桁架/地坪，补安全通道线、基座黄黑警示带、架空管线 |

**关键约束**：机械臂工作站属"场景资产"（与既有行车、管架同类，不进台账），
但**警示浮标必须由真实台账状态驱动** —— 由 `refreshFaultFloats()` 读取真实设备的
坐标与状态生成，绝不随机生成。

**布局冲突（实测踩到）**：`grid` 布局 16 台时设备落在 **z≈±3.7**，
而传送带在 z≈0、机械臂在 z≈±4.15 —— 会穿模。
因此产线启用时 `build()` 强制 `layout = 'wall'`（沿墙两排），把中轴让给产线。

## 三、P1 厂区总览 + 故障定位

- `factoryOverview.ts`：厂房清单由**台账真实 `workshop` 字段去重**生成（上限 5 栋），
  程序化排布 + 道路 + 空地 + 顶部名称标签；每栋带可拾取体，点击下钻。
  台账为空时走 `defaultBuildingSpecs()` 占位文案（不是假数据，只是占位）。
- `faultLocator.ts`：设备故障时在故障部位生成红色定位标
  （圆圈 + 十字 + `故障位置：xxx` 发光标签，Sprite 实现），带脉动；
  `focusPointOf(deviceId)` 供相机聚焦时对准该部位；设备恢复后 `clear()` 移除。

## 四、P2 大屏 HUD

`ProductionHUD.tsx`（HTML absolute 覆盖层，深色半透明 + 青色发光描边，
`pointer-events` 只开在控件上，不挡 3D 交互）：

- **顶栏**：生产管理 / Production Management + 面包屑（厂区总览 / 厂房 / 设备）+ 日期时间 + FPS
- **左侧**：设备列表 / 生产计划 / 质量管控 / 能耗分析 / 维护保养 / 人员管理 / 系统设置
  （点击联动右侧标签页），下方是真实台账设备快选（带状态色点）
- **右侧**：总览 / 参数 / 告警 / 日志 / 权限 / 设备管理

**数据纪律**：全部来自 `equipmentApi` / `workOrderApi` 真实接口。
遥测缺测（null）显示 `—`，不补零。
**产量 / 良率 / 能耗现有接口未接入** —— HUD 中明确标注"未接入"，不做推算、不模拟。

真实可用指标：电流 / 温度 / 转速 / 振动 / 电压 / 压力 / 负载率 / 健康分 / 48h 峰值振动，
运行状态曲线基于 `telemetry-history` 真实落库时序绘制。

## 五、P3 润色与性能

- 扫描线（沿 X 往复的发光窄带）+ 地面网格呼吸（复用既有 grid）
- 选中设备高亮环：复用既有 `selectionRing`
- 相机：既有自研轨道（环绕 + 滚轮缩放），聚焦时由 `frameIsolated()` 自动限位
- 动画：`setLayerAnimationsPaused()` 暂停 / `resetLayerAnimations()` 复位；
  HUD「系统设置」里有 **生产线 / 传送带动画 / 暂停动画** 三个开关，
  帧率不足时**可只关传送带动画而保留静态产线**
- Draw Call 控制：机械臂各站共享 geometry 与 material；滚轮、物料箱用 InstancedMesh
