## 三、PGlite 答辩口径（3 句话）

1. **零依赖开箱即跑**：PGlite 是 PostgreSQL 的 WASM 嵌入式版本，评审环境无需预装任何数据库，`docker compose up -d` 一条命令即可运行。

2. **标准 SQL 与 PG 全兼容**：23 个迁移文件在 PGlite 和 PostgreSQL 16.15 上均零冲突实测通过，业务代码无需任何修改。

3. **一行环境变量切生产**：生产部署时设置 `DB_TYPE=postgres` + `DATABASE_URL=postgresql://...` 即可切换到独立 PostgreSQL 实例，已实证迁移覆盖全部 29 张表。

**关键声明**：PGlite 是演示形态，不是生产级数据库。生产环境必须迁移到独立 PostgreSQL，当前已通过 `scripts/pg-migration-replay.ts` 实证兼容性。
