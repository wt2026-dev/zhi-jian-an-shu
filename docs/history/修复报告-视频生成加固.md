## 2. 最终配置项与环境变量清单

| 环境变量 | 默认值 | 说明 |
|----------|--------|------|
| `AGNES_ENABLED` | `false`（未配置时） | 功能总开关，设为 `"true"` 启用视频生成 |

- `getAgnesTotalTimeoutMin(): number`

## 3. URL 校验规则说明

`validateDownloadUrl(rawUrl)` 校验逻辑：

1. **协议限制**：仅允许 `http:` / `https:`，拒绝 `ftp:` / `file:` 等
2. **内网 IP 拒绝**：`localhost`、`127.x`、`10.x`、`172.16-31.x`、`192.168.x`、`169.254.x`、`0.x`、`::1`
3. **域名白名单**：配置 `AGNES_DOWNLOAD_HOST_WHITELIST` 后仅允许名单内域名

**绕过测试结果**：
- `ftp://evil.com/secret.mp4` → 拒绝（协议）
- `http://localhost:3000/secret.mp4` → 拒绝（内网）
- `http://10.0.0.1/secret.mp4` → 拒绝（内网）
- `http://172.16.0.1/secret.mp4` → 拒绝（内网）
- `http://192.168.1.1/secret.mp4` → 拒绝（内网）
- `http://169.254.1.1/secret.mp4` → 拒绝（内网）
- `not-a-url` → 拒绝（格式非法）
- `https://cdn.agnes-ai.cn/videos/abc.mp4` → ✅ 通过

## 5. 遗留风险与说明

1. **Agnes 侧限频对超时的影响**：Agnes 视频生成限频约 1 次/分钟，多段任务段间等待 65 秒。单段轮询窗口 20 分钟，全局超时 120 分钟（默认值，见上表）。

   > **2026-09-17 更新：超时的真实根因不是轮询窗口，而是 prompt 语言。**
   >
   > 此前把单段轮询窗口从 10 分钟放宽到 20 分钟，任务 `full-1789621230669` 仍在**整 20 分钟**处失败，说明"窗口不够"的假设不成立。
   >
   > 同一账号、同一时刻、同一 payload（441 帧 / 1088x832 / 24fps / `agnes-video-v2.0`）的对照实测：
   >
   > | prompt 语言 | 结果 |
   > |------|------|
   > | 英文（仅标题与解说词为中文） | **262 秒完成** |
   > | 全中文（大模型直出） | **13.6 分钟仍停在 `internal_status=inference`**，最终耗尽 20 分钟窗口 |
   >
   > 失败任务的远端快照亦证实：`created_at` 与任务创建时间仅差 5 秒（不存在提交延迟），
   > 20 分钟内始终 `status=in_progress / internal_status=inference / progress=30`、`completed_at=null`。
   >
   > 结论：**Agnes 对"整段中文 prompt"会长时间卡在推理阶段**。修复方式是在 `buildFullSegmentPrompt`
   > 中加语言护栏（`cjkRatio` + `MAX_PROMPT_CJK_RATIO = 0.45`，实测英文模板 26.6% / 全中文 90.0%），
   > 中文占比超阈值即丢弃大模型输出、改用英文备用模板。修复后第 1 段 **4.3 分钟完成**（轮询第 17 轮）。

2. **Agnes 无法渲染中文文字（新增，2026-09-17）**：即便 prompt 要求"画面顶部红色中文大标题"，
   Agnes 会在正确位置画出标题，但**字形是乱码**（如把"第1步：泵组运行参数记录与渗漏跑冒滴漏排查"
   渲染成"業11.毕 笄: 誒浹廩叕与ヲ与隟隟隟隟隟隟隟空"），且标题只出现数秒即消失，不满足"贯穿全片"。
   **建议：不再要求视频模型写字，改为用 FFmpeg `drawtext` 在成片上确定性烧录中文标题**
   （见 `scripts/burn-step-titles.mjs`，已验证可渲染出清晰可读的中文红底白字标题）。

2. **并发计数 finally 释放**：已在 `runFullVideoGeneration` 的 `finally` 块中执行 `runningTasks--`，确保无论成功/失败/超时都释放计数。这是此类修复最常见的翻车点——计数泄漏会导致功能永久锁死。

3. **审计日志**：当前任务 2 中的 `VIDEO_GEN_START` / `VIDEO_GEN_FAILED` 审计日志写入通过 `console.error` / `console.log` 输出。完整审计日志集成需要 `addAuditLog` 的 `req` 对象，而 `runFullVideoGeneration` 是后台异步执行无 `req` 可用。如需完整审计，建议在路由层（`handleGenerateVideoFull`）写 `VIDEO_GEN_START`，在 `runFullVideoGeneration` 中通过事件回调写 `VIDEO_GEN_FAILED`。

4. **配置热更新**：`isAgnesEnabled()` 等函数每次调用都读取 `process.env`，支持运行时通过 `process.env.AGNES_ENABLED = "true"` 动态开启，无需重启服务。
